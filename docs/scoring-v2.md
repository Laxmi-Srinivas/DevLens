DevLens Scoring Specification v2

1. Goal
    DevLens evaluates the quality of a developer's GitHub portfolio by analyzing repository quality, professional profile, technical breadth, consistency, and community impact. The score reflects the strength of the GitHub portfolio—not the developer's overall programming ability.
2. Scoring Philosophy

3. Categories

Repository Quality	    How well repositories are maintained
Community Impact	    How much attention the projects receive
Technical Breadth	    Variety of technologies and project types
Professional Profile	Profile completeness and presentation
consistency	            Activity and maintenance
Portfolio Diversity     Variety in project domains
